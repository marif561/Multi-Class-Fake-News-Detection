# Multi-Class-Fake-News-Detection
 In this paper, we discuss using different algorithms for the multiclass and cross-lingual fake news detection task. We achieved a macro F1-score of 28.60% for a mono-lingual task in English (task 3a) using RoBERTa pre-trained model and 17.21% for a cross-lingual task for English and German (task 3b) using Bi-LSTM deep learning algorithm.
